# 🌍 世界引擎（SillyTavern 扩展）

独立 API 世界推演引擎：对话结束后后台世界自动向前推演，把最新的世界状态注入模型正文；支持聊天级存档随聊天保存、跨设备同步、批量重填、资产账本与角色幕后推演。

- 作者：Disnight（原作者）
- 版本：v3.1.0
- 许可：MIT

## 功能清单

### 世界引擎（核心）
- **自动推演**：每轮对话后按「因果顺序」推演世界状态——事件链、势力、天下大势、风声、声誉、经济、仇敌、信息黑盒、区域事件等。
- **分层注入**：世界状态按对话层数注入模型正文，重 roll / 滑动重生成时注入存档点（该层正文产生前的世界状态）。
- **本地机制**：近端/远方随机事件、事件骰子、风声消散、事件链归并去重，参数全部可在设置中调整。
- **聊天级存档**：存档随聊天 JSONL 保存，支持跨设备同步、防丢失自动备份、存档点（checkpoint）恢复与回退。
- **世界书联动**：蓝绿灯触发（常驻 / 关键词命中），世界书内容进入推演 prompt。
- **批量重填**：从首个 AI 楼层分批推演到指定楼层，切聊天自动中止，防跨聊天污染。
- **引擎预设**：推演 prompt 各段（角色、因果步骤、输出格式、JSON 示例）可自定义覆写。
- **注入自检**：只读展示实际发给模型的 prompt 链，判断注入是否真正进入正文。

### 记忆引擎
- 人物与实体记忆（独立数据与故障边界）、纪要与总述自动整理、跨聊天存档重定位、手动/批量重填、快照导入导出。

### 资产账本（v3.1.0 新增，默认关闭）
- 「记账员」：推演时同步维护资产、产业、势力与资金账目；保留重大结算门禁——距上次完整结算不足阈值轮次且无重大结算事件时仅轻量更新时间；满阈值或发生大额交易、战损、收购等重大结算事件时完整记账并同步产出风声/事件链。

### 角色幕后推演（v3.1.0 新增，默认关闭）
- 不在场角色按自己的日程生活、社交、行动；维护幕后角色档案 + 后台动态日志 + 社交圈（地缘/业缘/血缘/志缘/利缘五类）；严格遵守感知边界，幕后私密行动不进入风声/声誉/事件链。

## 安装方式

1. 把本目录（或打包 zip）放入 SillyTavern 扩展目录：`SillyTavern/data/<user>/extensions/world-engine/`。
2. 重启 SillyTavern（或刷新页面），在扩展管理中找到「🌍 世界引擎」并启用。
3. 在「世界引擎」设置页填入 API 地址 / Key / 模型，点击「获取列表 / 测试连接」验证连通性，保存后即可使用。

> 注意：`data/<user>/extensions/` 是用户数据目录下的扩展路径；不同版本酒馆的目录结构略有差异，以你当前部署为准。

## 升级说明（v3.0.2 → v3.1.0）

- **存档完全兼容**：旧存档（v3.0.x 及更早）可直接使用，`ensureArrays` 迁移逻辑会自动补齐缺失字段；升级后首次打开聊天即可继续推演，无需重置或迁移操作。
- **新功能默认关闭**：资产账本与角色幕后推演两项功能均默认关闭，不开启时行为与旧版完全一致（零行为改变）。
- **开启方式**：设置页新增「资产·幕后」选项卡，分别打开资产账本 / 角色幕后推演总开关，按需调整账目类别、结算门禁、角色/日志/社交圈上限。
- **酒馆版本要求**：v3.1.0 修复了切聊天事件绑定，兼容酒馆 1.14.0（已移除 `CHAT_LOADED`，改用 `CHAT_CHANGED`/`chat_id_changed`）及旧版本酒馆。
- **界面变化**：主页展开模式、资源子视图与存档点视图新增「资产账本」「幕后推演」区块；「获取列表」按钮改名为「获取列表 / 测试连接」，点击会先保存当前表单再请求模型列表验证连接。
