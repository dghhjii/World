# 🌍 世界引擎 v3.1.0 使用指南

> 独立 API 世界推演引擎（SillyTavern 扩展）：对话后后台世界自动推进，注入最新世界状态；含资产账本、角色幕后推演、记忆引擎。
> 作者：Disnight（原版）· 增强：Mumu（资产账本/幕后推演/思维链/v5.7 精华）

---

## 一、安装与启用

### 安装（三步）
1. 把 `world-engine` 文件夹放入酒馆扩展目录：
   `data/<你的用户>/extensions/world-engine/`
2. 重启酒馆（或 F5 刷新页面）
3. 打开「扩展」面板 → 找到「🌍 世界引擎」→ 点启用

### 启用后第一件事：配 API
点输入框旁边的 🌍 悬浮球 → 面板 → 设置 →「API 设置」：

| 字段 | 说明 |
|---|---|
| 连接方式 | **直连**（默认，第三方 API 允许 CORS 时用）/ **经酒馆代理**（API 有 CORS 限制时用，推荐先试这个） |
| API URL | OpenAI 兼容地址，填到版本前缀一级（如 `https://api.openai.com/v1`、火山方舟 `https://ark.cn-beijing.volces.com/api/v3`） |
| API Key | 你的密钥 |
| 模型 | 推演用的模型（可单独选便宜的，不占正文模型额度） |
| 获取列表 / 测试连接 | 先保存再拉模型列表，可兼作连通性测试 |

> ⚠️ **推演失败 NetworkError？** 99% 是 CORS——把连接方式切「经酒馆代理」。
> ⚠️ 世界引擎的 API 与酒馆正文模型是**两套独立配置**，互不影响。

## 二、世界引擎（核心）

### 自动推演
每轮对话后，后台调用独立 API 推演世界状态，返回 JSON 字段：
`events（事件链）/ factions（势力）/ worldTrends（天下大势）/ winds（风声）/ economy（经济）/ reputation（声誉）/ enemies（仇敌录）/ influenceChain（影响链）/ blackbox（信息黑盒）/ assets（资产账本）/ offscreen + socialCircles（幕后推演）`

### 注入
世界状态按对话层数注入正文【世界信息】块；重 roll / 滑动重生成时注入**存档点**（该层正文产生前的世界状态）。

### 本地机制（设置 → 本地机制）
- 区域突发事件：本地骰子判定 + 类型加权（盗匪/大火/疫病…12 类）
- 近端随机事件：与当前剧情有因果的新事件/风声（Lv2-3）
- 远方随机事件：账本积累到门槛后按概率生成无直接关系的事件/风声
- 事件骰子：事件链每阶段 9 格推进（冲突型：萌芽→发酵→逼近→已爆发）
- 风声消散：按类型衰减曲线，未更新持续累积沉寂后消散
- 保留上限：各实体数组上限

### 批量重填
设置 → 高级 → 批量重填世界推演：从第 1 个 AI 楼层分批重推（清空重来），可指定批次大小/结束楼层/重试次数。

### 世界书联动（设置 → 世界书）
蓝绿灯触发：🔵 常驻条目恒注入、🟢 关键词条目仅命中时注入（复刻酒馆匹配规则，中文子串匹配），每条可单独覆写。

### 引擎预设（设置 → 调试）
推演 prompt 四段（引擎角色/因果步骤/输出格式/JSON 示例）可编辑成预设。

### 🧠 推演思维链（新增）
推演模型现在会先输出 `<thinking>` 思考过程（100-300 字）再输出 JSON。
查看：设置 → 调试 →「🧠 推演思维链」卡片（点开看本轮判断依据/因果链/取舍理由），下面「AI 返回」是完整原始输出。

### 字数（新增）
事件/风声/影响链/大势描述要求 120-200 字，JSON 示例示范详细度——推演内容不再是一句话。

## 三、资产账本（v3.1.0 新增，默认关闭）

### 开启
设置 →「资产·幕后」→ 打开「启用资产账本」→ 保存。

### 设置项
| 设置 | 说明 |
|---|---|
| 账目类别 | 记账员只记录这些类别（默认：产业/资产/资金/势力） |
| 完整结算门禁 | 距上次完整结算不足 N 轮（或 N 故事日）且无重大事件 → 只更新时间不重写账目 |
| 门禁模式 | **按轮**（默认）/ **按故事时间**（需要正文里有日期，配合「按时间推演模式」的日期正则） |
| 记账思考流程（COT） | 记账前 3 步强制思考（门禁裁定→收支预验证→自检），默认开 |
| 账目条目上限 / 重大事件记录上限 | 数组容量 |

### 记账质量守则（内置）
1. 数字可追溯：汇总必须可溯源到明细
2. 百分比落地：基数 × 比率 = 绝对值
3. 无变动要有原因：Δ=0 也要写为什么
4. 删减禁令：常设条目不得静默消失，消失必须写明原因
5. 闭环优先：资金/库存写 期初+流入-流出=期末
6. 个人资金隔离：主人的随身收支不算账本资产

### 重大结算事件（触发完整记账 + 自动出风声/事件链）
大额交易 / 开张营业 / 营业周期 / 战损 / 收购落地 / 迁入迁出 / 投资理财 / 获得新资产 / 破产 / 融资 / 大额支出 / 产业升级 / **人事调度 / 制度变更 / 灾害**
（个人资金变动不计入）

### 面板查看
主页展开模式 / 资源子视图 →「💰 资产账本」：上次结算时间、概览四格（宏观/分布/生产/资金）、账目条目（类别/名称/数值/变化/备注）、重大结算事件。

## 四、角色幕后推演（v3.1.0 新增，默认关闭）

### 开启
设置 →「资产·幕后」→ 打开「启用角色幕后推演」→ 保存。

### 三块状态
| 块 | 内容 |
|---|---|
| 幕后角色档案 | 不在场角色：位置/当前动向/目标/状态，全量维护、id 认领防顶替 |
| 后台动态日志 | 每轮 1-3 条「角色做了什么事」，同轮同动态去重，上限 16 条 |
| 社交圈 | 地缘/业缘/血缘/志缘/利缘五类；**活跃角色/关联团体/关联圈交集**把圈子连成「人-圈-组织」网络 |

### 核心约束
- 后台角色私密行动不进入风声/声誉/事件链（感知边界）
- 不替主人做决定、不虚构传播
- 本轮刚活跃的角色即使 API 漏返回也保留（防误删）

## 五、记忆引擎

人物/实体记忆（按组织/物品/能力/地点分类）、纪要与总述自动整理、时间线、批量重填、快照导入导出。与世界推演可联动（设置 → 联动 → 世界→记忆）。


## 八、常见问题

**Q: 推演失败 NetworkError？**
A: 连接方式切「经酒馆代理」。还不行就检查 URL 是否填到版本前缀级。

**Q: 推演内容还是几十个字？**
A: 先 F5 刷新（旧 JS 还在跑）；新推演才会用 120-200 字要求；旧数据不会自动变长。

**Q: 旧存档会坏吗？**
A: 不会。新字段全部默认值迁移（core.ensureArrays），零行为改变；新功能默认关闭。

**Q: 资产账本为什么一直不记账？**
A: 检查「启用资产账本」开了没；开了的话第一轮会强制完整记账（首次建立账本），之后按门禁节流。看推演有没有跑成功（状态栏）。

**Q: 想在 TauriTavern 用？**
A: 把 world-engine 文件夹复制到 TauriTavern 的扩展目录（%APPDATA%\com.tauritavern.client\...\extensions\world-engine）再启用。

**Q: 怎么确认注入真的进了正文？**
A: 设置 → 调试 →「注入自检」：显示实际发给模型的 prompt 链，判定 ✅已进正文 / ❌未进正文。
