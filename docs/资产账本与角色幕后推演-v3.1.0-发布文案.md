# 世界引擎 v3.1.0 —— 资产账本 + 角色幕后推演

## 更新日志

- 新增「资产账本（记账员）」：对话推演时同步维护 {{user}} 的资产、产业、势力与资金账目。保留主人「资产账本预设」的记账员思路与重大结算门禁设计：距上次完整结算不足阈值轮次、且本轮无重大结算事件时，只更新结算时间、不重写账目；满阈值或发生大额交易/开张营业/战损/收购落地/迁入迁出/投资理财/获得新资产等重大结算事件时，完整记账并同步产出风声/事件链。
- 新增「角色幕后推演」：推演不在 {{user}} 视线内的角色——他们按自己的日程生活、社交、行动。维护「幕后角色档案 + 后台动态日志 + 社交圈」三块状态；社交圈支持地缘/业缘/血缘/志缘/利缘五类。严格遵守感知边界：幕后私密行动不进入风声/声誉/事件链。
- 两项新功能均默认关闭，不开启时与旧版行为完全一致（零行为改变）；开启后推演 prompt、正文注入与面板同步增强。
- 设置页新增「资产·幕后」选项卡：资产账本（总开关/账目类别/结算门禁/上限）与角色幕后推演（总开关/角色上限/日志上限/社交圈上限）。
- 主页展开模式、资源子视图与存档点视图均新增「资产账本」「幕后推演」两个 section。
- 世界规则新增模块十三（资产账本）与模块十四（角色幕后推演），与推演 prompt 联动约束。

## 可直接复制的发帖文案

【世界引擎 v3.1.0 更新】

这次加入了两大新能力：

💰 资产账本（记账员）：世界推演时同步记账，资产/产业/势力/资金动态可追溯。带「重大结算门禁」——距离上次完整结算不足阈值轮次且无重大事件时只轻量更新，省 token 又保连续性；大额交易、战损、收购等重大事件触发完整结算，并自动生成风声和事件链。

🎭 角色幕后推演：不在场的角色也在过自己的生活。维护幕后角色档案 + 后台动态日志 + 社交圈（地缘/业缘/血缘/志缘/利缘），严格遵守感知边界，私密行动不会凭空泄露。

两项都默认关闭，打开才生效，对现有存档零影响。设置页新增「资产·幕后」选项卡，面板新增对应区块。
